# 机器学习入门路线（公开经验整理）

> 来源：红色石头《我的机器学习入门路线图》（2018，CSDN/公众号）、吴恩达 Coursera《Machine Learning》课程页、B 站相关公开课。
> 说明：路线是公开经验的整理，不是唯一答案；按自己的基础和目标裁剪。

## 两个「放弃」

1. **放弃海量资料**：先选定一条主线，不要囤几十 G 网课。资料越多越容易只收藏不学习。
2. **放弃从零起步**：不要一上来啃概率论、线代、凸优化的完整推导。先建立顶层框架，再从实践回到理论，缺什么补什么。

## 推荐顺序（入门）

1. **吴恩达 Machine Learning**：覆盖线性回归、逻辑回归、SVM、神经网络、K-Means、异常检测等，公式推导少，适合快速建立全局认识。作业有 Python 版本（GitHub 上的 `coursera-ml-py` 等移植）。
2. **林轩田《机器学习基石》**：比吴恩达更难，偏理论，配套教材《Learning From Data》。适合想补理论的人。
3. **周志华《机器学习》（西瓜书）**：体系完整，适合当参考书，不建议从第一页硬啃。
4. **《深度学习》（花书）**：偏理论，入门阶段不必通读；做深度学习项目时按需查。
5. **实践**：每学完一个模型，用 sklearn 在一个小数据集上跑通「训练→评估→调参」，再回来看公式。

## 数学怎么补（按需）

- 线性代数：矩阵乘法、向量空间、特征值分解、SVD。做 ML 时优先理解「矩阵是变换」。
- 概率统计：随机变量、常见分布、期望方差、最大似然、贝叶斯。
- 微积分：偏导、梯度、链式法则、泰勒展开；反向传播就是链式法则。
- 优化：梯度下降、凸性、拉格朗日乘子；先会用，再补证明。

## 时间安排（参考）

- 第 1–2 周：Python + numpy/pandas/matplotlib，能读 CSV、画图、跑 sklearn。
- 第 3–6 周：吴恩达课程前半 + 线性回归/逻辑回归，手写一遍梯度下降。
- 第 7–10 周：SVM、决策树、集成方法，每个模型做一次小实验。
- 第 11–14 周：神经网络基础 + 一个完整项目（数据清洗、训练、评估、报告）。
- 之后：按方向选（CV/NLP/推荐），不要同时开三个方向。

## 检验方式

- 能不看资料解释偏差-方差权衡、过拟合、正则化。
- 能在给定数据集上选择合适的评估指标并说明理由。
- 能复现一个基线模型，并说清每个超参数的作用。
