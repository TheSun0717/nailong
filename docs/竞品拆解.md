# 同类产品拆解与取舍（2026-10）

> 目的：确定奶龙学习助手「做什么 / 不做什么」。信息来源为公开报道与产品页，未做二进制逆向；厂商通稿中的数据未独立核验。

## 1. 作业帮学习机（AI 超级老师，2026-08 发布）

公开能力：

- 学情诊断 → 错因溯源 → 薄弱知识点定位的闭环，号称细到「每个填空、地级市」的知识图谱。
- 个性化学习规划，按学情每周更新课程方案。
- 全场景答疑（作业、阅读写作、第三方应用内随时问）。
- 本地化内容体系：覆盖 369 个地级市的「本地学练考」。
- 理化实验室：可视化交互理解理化知识。
- 家长侧：远程布置、托管盯学。

来源：[央广网](https://tech.cnr.cn/techph/20260817/t20260817_527765449.shtml)、[中新网](http://m.chinanews.com/wap/detail/zw/cj/2026/08-18/10679412.shtml)

## 2. 小猿搜题 / 夸克学习

- 小猿：题库与视频精讲强，定位「解题」；公开分析指出其 AI 对话助手能力相对弱。
- 夸克：覆盖学科广、功能多，但讲解质量被用户吐槽「给类似题、不是原题」。
- 商业模式：VIP 订阅 + 课程付费。

来源：[知乎对比](https://www.zhihu.com/question/542347355)、[拍照搜题市场分析](https://m.sgpjbg.com/labelsyh/paizhaosoutiaigongjushichang/1/6593129.html)

## 3. 它们真正在卖的三个东西

1. **题库 + 知识图谱**：靠海量题目和标注做错因定位。这是重资产，个人产品做不了。
2. **本地化考情**：地级市维度的考纲、题型、真题。需要持续采购与人工维护。
3. **闭环学习计划**：诊断 → 计划 → 练 → 再诊断。核心是「每周更新」和「可执行」。

## 4. 奶龙采纳什么

| 采纳 | 做法 |
|---|---|
| 画像驱动 | 学段 / 地区 / 学校 / 专业 / 年级，直接影响检索排序和提示词 |
| 来源可追溯 | 每条资料标注来源；本地资料优先，通用建议明确标注 |
| 结构化学习路径 | 前置知识 → 分阶段周计划 → 资料 → 检验点 |
| 可视化解说 | 知识点生成交互式 HTML 动画（对应「理化实验室」的单点能力） |
| 拍题 | 图片 → OCR → 讲解（识别失败时明确提示） |

## 5. 奶龙不做什么（以及为什么）

- **不做通用题库**：没有数据授权，也没有维护团队。改为「用户自己的资料 + 公开通用资料」。
- **不伪造校内数据**：没有某校试卷就直说没有，不用模型编造「学长原话」。
- **不做全学科知识图谱**：个人产品维护不起。先用课程级 + 文档级检索（BM25），规模上来再考虑向量检索。
- **不做家长监控**：定位是个人学习助手，不是托管硬件。

## 6. 差异化

市面产品的核心资产是「它有的题」，奶龙的核心资产是「你自己的资料 + 你的画像」。同校讲义、老师划的重点、学长经验这些不公开、但最有用的东西，只能由用户导入；奶龙负责整理、检索和生成可执行计划。
